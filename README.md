# Microgravity and Gellan Gum Hydrogels

A computational research project investigating how microgravity may influence the formation and structure of gellan gum hydrogels under sequential triggering.

## Project status

Research groundwork and model development.

## Repository structure

- `docs/` — research question, literature review, and methodology
- `src/` — simulation source code
- `data/` — input data and parameter records
- `simulations/` — simulation configurations and run notes
- `results/` — numerical outputs
- `figures/` — plots and visualisations

## Research principles

- Distinguish established findings from hypotheses.
- Document assumptions, units, and parameter sources.
- Keep raw data separate from generated outputs.
- Make simulations reproducible.
- Validate model outputs before drawing conclusions.
